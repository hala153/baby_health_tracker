# Baby Health Tracker - نظام الرعاية الذكية لصحة المواليد

An intelligent newborn healthcare system with AI-powered growth prediction and cry analysis.

## 🎯 About the Project

A comprehensive web-based system designed to provide smart healthcare for newborns. It connects parents, doctors, nurses, and administrators, integrating an AI module for growth prediction and cry analysis.

## ✨ Key Features

- 👶 Growth Tracking & Prediction (AI): Predicts a child's growth based on WHO standards via a Python Flask API.
- 😢 Cry Analysis (AI): Analyzes crying patterns to determine the baby's needs.
- 💉 Vaccination Management: Tracks vaccination schedules and alerts for overdue doses.
- 💊 Prescription Management: Manages prescriptions with drug interaction warnings.
- 👥 Multi-Role Access: Separate dashboards for Admin, Doctors, Nurses, and Parents.
- 📊 Reporting & Analytics: Generates detailed reports with interactive charts.

## 🛠️ Technologies Used

- Backend: PHP, MySQL
- Frontend: JavaScript (AJAX), Bootstrap 5, Chart.js
- AI Module: Python (Flask API)
- Security: Prepared Statements, PDO, Session Management

## 🚀 Setup Instructions

1. Clone the repository
2. Import baby_tracker.sql into MySQL
3. Place files in XAMPP htdocs folder
4. Run pip install flask flask-cors numpy
5. Start Flask API: python app.py
6. Access via http://localhost/baby_health
